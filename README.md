# 橘猫桌宠

一只会在桌面上散步、蹭人、吃饭和睡觉的橘色虎斑猫桌面宠物。窗口透明、无边框、默认置顶，交互方式接近常见的 Shimeji / 桌宠小部件。

猫咪立绘为原创卡通动漫（chibi）透明 PNG **逐帧动画**：每个动作的每一步都有独立图片，而不是一张静图靠 CSS 晃动。不含任何受版权保护的角色。

## 环境要求

- Windows 10 / 11（主要目标平台）
- [Node.js](https://nodejs.org/) 18.18 或更高版本（建议 LTS）
- 能访问 npm 源

把整个项目复制到 Windows 电脑上即可，例如：

```bat
C:\work\news
```

## 安装与启动

在项目目录打开终端（PowerShell 或 cmd）：

```bat
cd /d C:\work\news
npm install
npm start
```

第一次启动会打开透明小窗，橘猫默认出现在屏幕右下角（任务栏上方）。任务栏不显示应用按钮，请看系统托盘里的猫脸图标。

开发时按 `F12` 可打开独立调试窗。

## 功能

- 始终置顶（可在菜单里取消）
- 拖动猫咪到屏幕任意位置
- 松开后如果还在半空，会有简单重力掉回桌面底部
- 碰到屏幕边缘会转身，不会走出工作区
- 空闲时自动散步、坐下、睡觉、伸懒腰、舔毛
- 左键摸摸，双击会开心蹦跳
- 右键中文菜单：摸摸、喂食、玩耍、睡觉、跟随鼠标、置顶、隐藏到托盘、退出
- 饥饿 / 心情 0–100，会缓慢下降；喂食和摸摸可以恢复；悬停或菜单「显示状态」查看
- 系统托盘：单击显示/隐藏，右键退出等
- 跟随鼠标模式
- 静音开关；未静音时用 Web Audio 发出短促喵声

设置（窗口位置、静音、跟随鼠标、置顶、状态栏钉住）会写到 Electron `userData` 下的 `deskpet-settings.json`。Windows 上大致在：

```
%APPDATA%\橘猫桌宠\deskpet-settings.json
```

## 操作一览

| 操作 | 效果 |
| --- | --- |
| 拖动 | 把猫抱到任何地方 |
| 左键单击 | 摸摸（开心 / 舔毛） |
| 左键双击 | 开心跳 + 喵一声 |
| 右键 | 打开菜单 |
| 摸摸 | 心情上升 |
| 喂食 | 吃小鱼，饱食上升 |
| 玩耍 | 追毛线球 |
| 睡觉 | 趴下打盹 |
| 跟随鼠标 | 猫走向指针附近 |
| 置顶 | 是否压在其他窗口上面 |
| 静音 | 开关音效 |
| 显示状态 | 钉住心情/饱食条 |
| 隐藏到托盘 | 小猫进托盘 |
| 托盘单击 | 显示或隐藏 |

饥饿太低时，猫咪更爱发呆，头顶会出现小鱼泡泡，提醒你喂食。

## 打包成 Windows 应用（可选）

```bat
npm run build:win
```

完成后在 `release` 目录里会有安装包（NSIS）和便携版。需要本机已执行过 `npm install`。

仅编译渲染进程、不打安装包：

```bat
npm run build
```

## 项目结构

```
src/main/        主进程：窗口、托盘、IPC、设置存盘
src/preload/     预加载桥
src/renderer/    状态机、逐帧动画循环、猫咪立绘与 HUD
src/renderer/src/assets/pet/<动作>/<帧>.png  512×512 逐帧透明 PNG
src/renderer/src/pet/clips.ts               动画剪辑表（帧序与间隔）
src/shared/      窗口尺寸与设置类型
resources/       应用图标 icon.png、托盘图标 tray.png
```

## 逐帧动画

精灵按动作分子目录，全部为 **512×512** 居中透明 PNG。`clips.ts` 组成循环 / 往返 / 播完停住 / 眨眼剪辑。渲染时用固定 168px 双缓冲交叉淡入，避免换帧闪白。走路素材朝右，朝左时水平翻转（`scaleX(-1)`）。

| 动作 | 帧文件 | 播放 |
| --- | --- | --- |
| walk | `01.png`–`06.png` | 行走循环，约 100ms/帧 |
| idle | `eyes-open` / `blink-half` / `blink-closed` | 多数时间睁眼，偶尔快速眨眼 |
| sleep | `01.png`–`04.png` | 缓慢来回呼吸 |
| happy | `01.png`–`04.png` | 快速来回蹦跳 |
| sit | `01.png`–`05.png` | 张望 + 眨眼 |
| stretch | `01.png`–`04.png` | 坐下 → 伸懒腰 → 打哈欠 |
| lick | `01.png`–`04.png` | 抬爪舔毛循环 |
| surprised | `01.png`–`04.png` | 惊吓后停住 |
| eat | `01.png`–`04.png` | 看鱼 → 咬 → 嚼 |

## 常见问题

**看不见猫？** 先看托盘区，点猫脸图标显示窗口。也可能被拖到另一块屏幕，重新删掉设置文件即可回右下角。

**窗口有白底？** 请用 `npm start`（Electron 透明窗）。用普通浏览器打开 `index.html` 看不到正确的桌宠效果。

**没有声音？** 右键确认没有勾选「静音」。系统本身也需要未静音。
